## W4a: hooks, CLI flags, skills, sub-agents, rewind, misc

1. Hooks: emit the 17 never-fired events from their natural trigger points
   with the payloads named in the brief (Setup, UserPromptExpansion,
   MessageDisplay, TaskCreated, TaskCompleted, StopFailure,
   InstructionsLoaded, ConfigChange, CwdChanged, DirectoryAdded,
   FileChanged, WorktreeCreated, WorktreeRemoved, PreModelSwitch,
   PostModelSwitch, ElicitationRequest, ElicitationResponse); remove them
   from NOT_EMITTED_V1; one test per event with a command hook that writes
   its stdin to a file; README's never-fired list updated.
2. Flags, implement the 21 listed in the brief; declare the 7 cloud/IDE
   flags not applicable with the one-line reason in the notice and in
   docs/COMMANDS.md; `--safe-mode` accepted with no effect and documented
   as such; the README `--debug` troubleshooting line corrected; a test
   asserts no flag remains in the not-yet list except by design.
3. Skills: `context: fork` / `agent` run the skill in a sub-agent through
   the existing sub-agent machinery.
4. Sub-agents: AskUserQuestion and ExitPlanMode in children forward a card
   to the parent dock tagged with the agent name (the W3a queue); background
   sub-agents forward live permission asks the same way instead of
   immediate denial; the SubAgentCard phase word fix if W3b did not land it.
5. /rewind: steps record files CREATED so undo deletes them; Bash and
   NotebookEdit changes are shadow-copied via a git status diff before and
   after the command when the cwd is a git repo, with the documented limit
   for non-git directories.
6. Misc: agent frontmatter `memory:` honoured (`~/.halo/agents/<name>/`);
   `isolation: worktree` for sub-agents (shared with `--worktree`);
   `--file file_id:path` stays notice-only with the reason; print-mode json
   gains `duration_ms` and `uuid`; `stats --models` per-model `turns` real;
   unresolved `@server:uri` mentions warn visibly naming the server;
   `/compact` typed mid-turn is queued and runs when the turn ends.
