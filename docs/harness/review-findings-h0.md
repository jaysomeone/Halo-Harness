2. **major** — `halo_harness/config/paths.py:185` — `memory_dir` builds the slug from the raw cwd instead of the git root when inside a repo ([bin §12]), and at :180-184 honours `autoMemoryDirectory` from any merged layer (including untrusted project settings; [bin]: never project) without `~` expansion. — From `…\halo\tests` H0 reads `C--Users-user-Documents-vibes-appDev-halo-tests\memory` while Claude Code uses `…-halo\memory` (verified), and `--cwd .` gives slug `-` plus "Working directory: ." in the prompt, so project memory silently disappears and H1 memory writes would go where Claude Code never looks. — Resolve cwd to an absolute path once in `headless`, slug the git toplevel (the same `.git` walk the trust check uses) or else cwd, and read `autoMemoryDirectory` only from policy/flag/local/user with `expanduser`.

3. **major** — `halo_harness/agent/loop.py:261` — `_stream_one` drains the whole `stream_completion` generator into `wire_events` before `turn()` yields anything, and never closes `gen` when `handle()` raises. — A 90-second DeepSeek answer prints nothing in `-p` text mode until it is complete, no interrupt can land mid-reply because the whole stream runs inside one `next()`, and a dict-valued `delta.content` (passed through by `oai_stream` as `text: {…}`, verified) raises TypeError at :239, killing `-p` with a traceback while the reader thread keeps streaming. — Make `_stream_one` a generator that yields each translated Event as its wire event arrives, type-checks payload text, commits the assistant message only after the terminal event, and closes `gen` in `finally`.

4. **major** — `halo_harness/providers/stream.py:360` — The upstream is shut down only when `abort` is set, through `result.conn.sock` (which http.client has already set to None when the upstream answers `Connection: close`); `_run_phase1` never checks `abort`, and `loop.py:186` passes none. — A consumer that stops with `gen.close()`, raises, is garbage-collected or hits the malformed-data `break` leaves the daemon reader pulling billed tokens until the model finishes (the proxy now does this too if the client vanishes between phase 1 and the header write, because `bridge.py:289-303` runs outside the try/finally while the reader already runs), and an interrupt during time-to-first-byte waits out up to 2 × 300 s. — Shut the socket in `finally` unless a terminal event was consumed, keep the socket captured right after connect instead of reading `conn.sock` later, take `abort` in `_run_phase1` (check before each attempt; a watcher closes the pending socket), and pass it from the loop.

## H1 compatibility
- **`agent/loop.py` must be rewritten rather than extended.**
  - `self.messages` plus `session_store.py` (which never logs the system node or tools) conflict with rev. 1's log-derived requests.
  - There is no `Session.run()`, command queue or interrupt path.
  - There is no tool_use/tool_result pairing and no synthetic results (rev. 2), and thinking/tool_use blocks are not in Anthropic's canonical shape (rev. 6).
  - `oai_stream.py:205` mints fresh `toolu_` ids instead of keeping upstream ids verbatim (rev. 2, Kimi).
- **`agent/prompt.py` + `assemble.py`** put the date, git status/log, model label, MEMORY.md and the topic index in the system node. Rev. 3 moves all of that into user-role snapshots; the system node keeps identity → persona → plan policy → tool sentences → MCP instructions → cwd.
- **`providers/stream.py`** can keep its two-phase generator, exception types and reader/ping loop. What conflicts:
  - `CompletionRequest` needs a compat profile and dialect dispatch (rev. 5). Today every non-`databricks` provider goes to `call_openai_chat`, `anthropic-passthrough`/`ant:` routes are silently sent as OpenAI chat, and the `provider` field is sent to any host.
  - Reasoning must be captured (rev. 6): `emit_reasoning` is inert and `oai_stream` drops reasoning.
  - `clamp_max_tokens` skips its headroom check below the floor; rev. 7 wants an explicit budget instead.
  - `select_tools` pops `defer_loading` out of the caller's dicts and caps at 128, where Databricks needs 32 (rev. 4).
- **`headless._resolve_creds`** must read `effective_env` instead of the proxy's `load_settings_env_chain(Path.cwd())`, which reads managed settings from `%LOCALAPPDATA%`, gives them the lowest precedence, lets process env beat settings, and ignores `--cwd`. It must also send `x-databricks-use-coding-agent-mode`.
- **Default model and output:** `DEFAULT_MODEL_REF` is the unpinned V3.2 that revs. 12/13 retire. `output.py`'s `result` is every text delta of the turn joined together; it must become the final assistant message once tool loops produce intermediate text.
